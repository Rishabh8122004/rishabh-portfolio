# Rishabh's Portfolio

## About the Project

This is a responsive personal portfolio website created using HTML5 and CSS3 as part of the InternNova Full Stack Web Development internship.

The website presents my profile, education, skills, projects, resume, and contact information through a multi-page layout.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Website Pages

- **Home** – Introduction, profile image, and resume link
- **About Me** – Personal introduction
- **Skills** – Technical skills and skill descriptions
- **Education** – Educational background and achievements
- **Projects** – Projects with descriptions and technologies
- **Resume** – Professional summary and resume link
- **Contact** – Contact form

## Features

- Responsive design for desktop, tablet, and mobile devices
- Flexbox for navigation and major page layouts
- CSS Grid for skills, projects, and contact form layouts
- Media queries for responsive behavior
- Hover effects and CSS transitions
- Responsive profile image
- Styled buttons and form controls
- Working navigation links
- GitHub and LinkedIn links
- Downloadable/viewable resume
- External CSS stylesheet
