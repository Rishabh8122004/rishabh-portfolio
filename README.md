# Rishabh's Portfolio

## About the Project

This is a personal portfolio website created using HTML and CSS. It presents my profile, education, skills, projects, and contact information in a simple multi-page website.

## Technologies Used

* HTML5
* CSS3

## Website Pages

* **Home** – Introduction and profile
* **About Me** – Personal introduction
* **Skills** – Technical skills
* **Education** – Educational background
* **Projects** – Projects and work
* **Contact** – Contact form and information

## Features

* Multi-page portfolio website

* Contact form
